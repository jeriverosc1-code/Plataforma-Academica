## Descripción del proyecto

La Plataforma Académica Básica es un proyecto desarrollado para la asignatura Ingeniería de Software III.

El proyecto tiene como finalidad representar una plataforma sencilla para consultar información académica, como datos del estudiante, asignaturas y horario académico.

El proyecto se desarrolla como parte del taller de gestión colaborativa utilizando Git y GitHub, aplicando ramas, commits, repositorios remotos y Pull Requests.
